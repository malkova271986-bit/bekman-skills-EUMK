# Навыки Claude Е. В. Бэкман

В репозитории два навыка, каждый в своей папке:

- [`eumk-offline-html`](eumk-offline-html/SKILL.md) — ЭУМК в виде офлайн HTML-комплекса;
- [`academic-slides-bekman`](academic-slides-bekman/SKILL.md) — строгие академические презентации в авторском оформлении.

## ЭУМК в виде офлайн HTML-комплекса

Навык `eumk-offline-html` помогает Claude собрать электронный учебно-методический комплекс (ЭУМК) из папки Google Диска в офлайн HTML-комплекс:

- опись и сверка материалов (лекции, практические занятия, тесты, учебно-методическая карта, программа);
- связывание материалов гиперссылками и поиск по всем текстам;
- проверка ссылок и отображения;
- архив для Windows, который открывается без интернета и установки (двойной щелчок по `index.html`);
- отчёт о сверке для автора.

Сам навык — файл [`eumk-offline-html/SKILL.md`](eumk-offline-html/SKILL.md).

## Академические презентации

Навык `academic-slides-bekman` создаёт строгие академические презентации в оформлении Е. В. Бэкман (кремовый фон, шрифты EB Garamond и IBM Plex Sans, терракотовый акцент) на любую тему: отчёты, доклады, защиты, выступления на конференциях.

Сам навык — файл [`academic-slides-bekman/SKILL.md`](academic-slides-bekman/SKILL.md).

## Как установить навык в Claude

1. Скачайте папку нужного навыка и упакуйте её в ZIP-архив.
2. На claude.ai откройте «Настройки» → «Возможности» (Capabilities) → «Навыки» (Skills).
3. Нажмите «Загрузить навык» и выберите архив.
