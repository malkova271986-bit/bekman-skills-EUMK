# Навык Claude «ЭУМК в виде офлайн HTML-комплекса»

Автор: Е. В. Бэкман.

Навык `eumk-offline-html` помогает Claude собрать электронный учебно-методический комплекс (ЭУМК) из папки Google Диска в офлайн HTML-комплекс:

- опись и сверка материалов (лекции, практические занятия, тесты, учебно-методическая карта, программа);
- связывание материалов гиперссылками и поиск по всем текстам;
- проверка ссылок и отображения;
- архив для Windows, который открывается без интернета и установки (двойной щелчок по `index.html`);
- отчёт о сверке для автора.

Сам навык — файл [`eumk-offline-html/SKILL.md`](eumk-offline-html/SKILL.md).

## Как установить навык в Claude

1. Скачайте папку `eumk-offline-html` и упакуйте её в ZIP-архив.
2. На claude.ai откройте «Настройки» → «Возможности» (Capabilities) → «Навыки» (Skills).
3. Нажмите «Загрузить навык» и выберите архив.
